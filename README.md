# JavaScript Projects

A collection of small projects built using JavaScript to practice and demonstrate fundamental web development skills.

## Projects

### 1. Calculator
A functional calculator application built with HTML, CSS, and JavaScript.

**Features:**
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean and responsive user interface
- Real-time calculations

**Technologies:** HTML, CSS, JavaScript

**Location:** `/Calculator`

## Getting Started

Each project is contained in its own folder. To run a project:

1. Navigate to the project folder
2. Open the `index.html` file in your web browser
3. Interact with the application
